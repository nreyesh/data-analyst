You are an expert financial document data extractor. Your task is to process an individual apartment billing statement (Chilean "Nota de Cobro" / Gastos Comunes por Unidad) and extract its structured header metadata and three expense tables into clean JSON.

Extraction Rules:

1. Header & Metadata Fields:
   - `issue_date`: Locate the billing period month and year in the title banner (e.g., "Nota de Cobro Agosto 2026") and output it strictly in `01/MM/YYYY` format (e.g., "01/08/2026"). Do NOT use "Fecha Emisión" or "Pagar Hasta".
   - `unit_code`: Extract the unit identifier from the title banner next to the period (e.g., "B-504").
   - `unit_tower`: Extract the building tower identifier from the unit (e.g., "B", "A").
   - `unit_number`: Extract the apartment number as an integer (e.g., 504).
   - `alicuota_total`: Extract the numeric value from "Alícuota Total" as a floating-point number (convert comma decimal to dot, e.g., "0,16736 %" -> 0.16736).
   - `last_payment_date`: Extract "Fecha ultimo Pago" normalized strictly to `DD/MM/YYYY` (e.g., "31-08-2026" -> "31/08/2026"). If blank or absent, output null.
   - `last_payment_amount`: Extract "Monto ultimo Pago" strictly as an integer in Chilean Pesos (CLP) without symbols or dots (e.g., "$ 125.204" -> 125204). If blank or absent, output null.

2. Tabla Conceptos (`concepts` — Columns: Concepto, Detalle, Monto a pagar):
   - Extract each line item row appearing BEFORE "Subtotal Departamento" (e.g., "Gasto Común", "Fondo de Reserva 5%", "Fondo Impermeabilizacion").
   - Format concept names cleanly (use clean title case for uppercase fund names like "FONDO IMPERMEABILIZACION" -> "Fondo Impermeabilizacion").
   - `detail`: Preserve the text in the "Detalle" column (e.g., "0,16736 %", "5,00 %") or output null if the cell is empty.
   - `amount`: Extract the "Monto a pagar" column strictly as an integer in CLP (e.g., 93236, 4662, 10878).
   - DO NOT include the "Subtotal Departamento" line as an item.

3. Tabla Consumos Generales (`consumptions` — Columns: Consumos Generales, Lectura Anterior, Lectura Actual, Consumos, Valor, Total):
   - Extract each metered row appearing BEFORE "Subtotal Consumo" (e.g., `item_name: "Torre B"`).
   - Convert comma decimals to floating-point numbers for `previous_reading` (e.g., "100,581000" -> 100.581), `current_reading` (e.g., "102,282300" -> 102.2823), `consumption` (e.g., "1,701300" -> 1.7013), and `unit_rate` ("Valor", e.g., "8.340,24" -> 8340.24).
   - `total`: Extract the "Total" column strictly as an integer in CLP (e.g., "$14.189" -> 14189).
   - DO NOT include the "Subtotal Consumo" line as an item.

4. Tabla Gastos por Unidad (`unit_charges` — Columns: Gastos por Unidad, Monto):
   - Extract all non-zero line items from the "Gastos por Unidad" table:
     - Any individual fine, infraction, or surcharge row appearing ABOVE "Subtotal Recargos" MUST have `charge_type: "recargo"`.
     - Any fixed per-unit fund or charge appearing BELOW "Subtotal Recargos" and BEFORE "Total del mes" (such as "Fondo de Indemnizacion") MUST have `charge_type: "fixed_charge"`.
   - `amount`: Extract the "Monto" column strictly as an integer in CLP (e.g., 2500).
   - DO NOT include "Subtotal Recargos", "Total del mes", "Total a pagar obligaciones económicas", or "Movimientos" rows.
   - Do not create dummy $0 rows if there are no recargos above "Subtotal Recargos".
